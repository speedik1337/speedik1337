# Бот-магазин Telegram-подарков

Пользователь пополняет внутренний баланс (в сумах) картой **Humo / Uzcard** или **криптой**,
выбирает подарок по категории и отправляет его себе или другу. Подарки отправляются через
Bot API `sendGift` с баланса Stars бота.

## Возможности
- Каталог по категориям: недорогие (до 50⭐), средние, дорогие, премиум, лимитированные, «все»; постранично.
- Карточка подарка со стикером, ценой, остатком лимитки.
- Подпись к подарку, отправка себе или по Telegram ID.
- Баланс в сумах: пополнение готовыми суммами или своей.
  - 💳 Humo / Uzcard через встроенные платежи Telegram (провайдер **Click** или **Payme**).
  - 🪙 Крипта через **@CryptoBot** (USDT, TON, BTC и др.), счёт в UZS.
- Если подарок не отправился, деньги автоматически возвращаются на баланс.
- Админ: `/stats` (продажи, пополнения, баланс Stars), `/addbalance <id> <сумма>`.

## Настройка
1. `pip install -r requirements.txt`
2. `cp .env.example .env` и заполните:
   - `BOT_TOKEN` выдаёт @BotFather.
   - `CARD_PROVIDER_TOKEN`: @BotFather → /mybots → бот → Payments → Click или Payme
     (сначала можно взять тестовый токен, потом подключить боевой через договор с провайдером).
   - `CRYPTO_PAY_TOKEN`: @CryptoBot → Crypto Pay → Create App
     (для тестов @CryptoTestnetBot и `CRYPTO_PAY_URL=https://testnet-pay.crypt.bot/api`).
   - `STAR_PRICE_UZS`: ваша себестоимость 1 Star в сумах, `MARKUP_PERCENT`: наценка.
3. **Пополните баланс Stars у бота**, иначе подарки не отправятся.
4. `python -m bot.main`

Цена подарка = Stars × `STAR_PRICE_UZS` × (1 + `MARKUP_PERCENT`%), округляется вверх до 100 сум.
Способ оплаты, для которого не задан токен, просто не показывается.
